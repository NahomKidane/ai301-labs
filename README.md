# AI 301 Labs

Student copies of the notebooks for AI 301, Natural Language Processing and Conversational AI,
UTK College of Emerging and Collaborative Studies, Applied AI. 

Every notebook here opens in Google Colab. Use the link your instructor posted in Canvas, then
choose **File > Save a copy in Drive** before you start, so your work is saved to your own account.

## What is here

One folder per module, named `mNN-topic`. Inside each, guided labs and challenge labs.

Guided labs are practice and are never graded. Challenge labs are the graded assignment for the
module and are submitted in Canvas.


## Opening a notebook in Colab

Take the path to the notebook in this repository and put it after the Colab GitHub prefix:

```
https://colab.research.google.com/github/NAHOM/ai301-labs/blob/main/<path to the notebook>
```

## Corrections

Notebooks here are regenerated from the course source, so anything committed by hand will be
overwritten. Report a problem to the instructor rather than opening a pull request.
